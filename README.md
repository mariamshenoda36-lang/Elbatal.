# موقع مستر جورج البطل — نسخة بخادم وقاعدة بيانات

## ما الذي أصبح جاهزًا؟
- الواجهة الأصلية محفوظة داخل `public/index.html`.
- المواعيد والتعليقات تُقرأ وتُحفظ في قاعدة SQLite على الخادم بدل `localStorage`.
- لوحة الإدارة تتحقق من الرمز على الخادم، وليس داخل JavaScript.
- جلسة الإدارة في Cookie من نوع HttpOnly وSameSite، مع تحديد محاولات تسجيل الدخول.
- لا يوجد تسجيل دخول بالبريد الإلكتروني.

## تشغيل محليًا
يتطلب Node.js 20 أو أحدث:
1. `npm install`
2. أنشئ قيمة `SESSION_SECRET` عشوائية طويلة (32 حرفًا أو أكثر).
3. شغّل `npm run make-admin-hash` واكتب رمز الإدارة عند ظهور الطلب. سيطبع بصمة مشفرة؛ ضعها كاملة في متغير البيئة `ADMIN_CODE_HASH` بالشكل `salt:hash`.
4. شغّل الموقع مع المتغيرين:
   - `SESSION_SECRET`
   - `ADMIN_CODE_HASH`
   ثم `npm start`
5. افتح `http://localhost:3000`.

## النشر
ارفع المشروع إلى استضافة تدعم Node.js 20، واضبط متغيري البيئة السابقين، وخصص قرصًا دائمًا لملف SQLite (المتغير `DB_FILE`، مثل مسار القرص الدائم). استخدم HTTPS. لا تستخدم استضافة ملفات ثابتة فقط؛ هذه النسخة تحتاج خادم Node.js.
إذا كانت الاستضافة تشغّل أكثر من نسخة من الخادم، استخدم PostgreSQL بدل SQLite قبل التوسع.

- احمِ صفحة الإدارة ومعلومات الدخول، ولا تشاركها.
